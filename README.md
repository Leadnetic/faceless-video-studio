# Faceless Video Studio — Psychology Shorts

A self-contained Remotion studio for vertical psychology shorts (1080×1920, 30 fps). It is fully separate from the Leadnetic studio.

## Pipeline (per video)

```bash
# 1. Narration (local Kokoro TTS, no API costs) → public/audio/voiceover.wav + src/data/timeline.json
tools/tts/venv/bin/python tools/build_voiceover.py script/voiceover.json
# 2. Original score + SFX (synthesised, royalty-free) → public/audio/score.wav, public/audio/sfx/*
tools/tts/venv/bin/python tools/build_score.py
# 3. QA stills at chosen seconds → previews/
node tools/stills.mjs 0.5 6 12 18 24 31
# 4. Final render
npm run render        # → output/psychology-video-001.mp4
```

## Structure

| Path | Purpose |
|---|---|
| `script/voiceover.json` | Script lines, pauses, emphasis words, voice settings |
| `src/videos/video001.ts` | All content and timings for this video, anchored to narration (not to hard-coded seconds) |
| `src/PsychologyShort.tsx` | Main composition: scenes, captions, grain, music, and sound design |
| `src/scenes/S1–S6` | Individual animated scenes |
| `src/components/` | Reusable parts: `Atmosphere` (room, light cone, dust, floor), `Figure` (faceless character), `Messaging` (bubbles, typing, presence), `Captions`, `Primitives` (Scene, Sfx, Grain, Kicker, Reveal) |
| `src/lib/` | `anim` (easing/tween/keys), `camera` (virtual camera and parallax layers), `timeline` |
| `tools/` | TTS, score, and still-render scripts |

## Making video #2

1. Copy `script/voiceover.json` and change the lines.
2. Copy `src/videos/video001.ts` → `video002.ts` and change the bubbles, words, and scene windows.
3. Register it in `src/Root.tsx` and run the pipeline.

### Video 002 — "The Conversation Ended. Your Mind Didn't."

```bash
tools/tts/venv/bin/python tools/build_voiceover.py script/voiceover-002.json --audio-dir public/audio/v002 --timeline src/data/timeline-002.json
tools/tts/venv/bin/python tools/build_score_002.py
COMP=PsychologyShort002 PREFIX=v002/a node tools/stills.mjs 0.5 6 12 18 25 31
npx remotion render src/index.ts PsychologyShort002 output/psychology-video-002.mp4 --codec=h264 --crf=16
```

New reusable building blocks: `SevenSeg` (LED clock), `MemoryCard` (+ Chat/Pause/Face memories), `Rewind` (VHS overlay + tape jitter), `Corridor` (looping 2.5D arch corridor with billboards), `Orbit` (depth-sorted orbiting fragments), and `Figure` with `pose="seated"` / `stride`.

Requirements: the Kokoro model files (`tools/tts/kokoro-v1.0.onnx`, `voices-v1.0.bin`) come from the GitHub releases of `thewh1teagle/kokoro-onnx`.

## Setup in a fresh session (cloud or local)

```bash
npm install                                   # Remotion 4.0.290
python3 -m venv tools/tts/venv && tools/tts/venv/bin/pip install kokoro-onnx soundfile numpy
# Kokoro model files (local fallback voice, Apache-2.0) from the kokoro-onnx GitHub release:
curl -L -o tools/tts/kokoro-v1.0.onnx https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.0/kokoro-v1.0.onnx
curl -L -o tools/tts/voices-v1.0.bin  https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.0/voices-v1.0.bin
```

`public/audio/` is regenerated by the voice + score tools (only v017/v018 are committed).
